Prism Lens FX v1.0

A Premiere Pro panel that simulates the optical characteristics of Prism Lens FX physical filters using combinations of Premiere Pro's native video effects.

How to use: Select one or more clips in the timeline, choose an intensity, then click any effect button. The effect is applied immediately via native Premiere Pro effects — tweak parameters in the Effect Controls panel.

Effect Notes

Starburst / Flare — After applying, reposition the flare centre in Effect Controls → Lens Flare to match your practical light source.

Split Diopter — After applying, add a linear mask to the Gaussian Blur effect (Effect Controls → Gaussian Blur → Mask) to limit blur to one half of the frame.

Kaleidoscope — Adjust the Mirror Reflection Centre points in Effect Controls to control the symmetry axis.

Diagnostics

Select a clip in the timeline, then run the diagnostic to see exactly what the scripting layer can access.
